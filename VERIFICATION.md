# Проверки 0.4.0

- Подключена готовая база ARVIO: commit `814638307236adb8eb572ed343f126de46b61b27`.
- Патч проверен `git apply --check` на чистой исходной версии.
- LogicCheck адаптера прошёл: разрешения, идентичность эпизодов, приоритет звука, безопасные ссылки и поиск.
- Синтаксис Windows-установщика проверен PowerShell Parser. Полный Windows-сценарий здесь не исполнялся.
- Первая сборка новой базы упёрлась в лимит памяти Kotlin 2 ГБ. Повторная запущена с 4 ГБ для Kotlin, 2 ГБ для Gradle и без параллельных задач. Итог новой сборки будет записан после её завершения; проверка старого прототипа не считается проверкой ARVIO.
- Добавлен CinemaQualityTabsTest: группировка озвучек по доступным качествам, отсутствие пустых вкладок, автоматический выбор и контракт встроенного каталога.
- Эмулятор, реальный TV и телефон здесь не использовались. Проверки компиляции и контрактов не подтверждают внешний вид, фокус, воспроизведение и работу ARM-процесса на устройстве.
