# CinemaHall — собственный кинотеатр на основе Nuvio

## Принцип
CinemaHall использует исходные плееры и UX-фундамент Nuvio TV/Mobile (с соблюдением GPL-3.0), но **каталог и выбор просмотра принадлежат CinemaHall**. Zona — ориентир простого сценария, а не визуальная копия плеера.

### Пользовательский путь
1. Главная / Фильмы / Сериалы / Мультфильмы / Поиск / Моя библиотека — из CinemaHall API.
2. Карточка тайтла с широким фоном, постером, описанием, рейтингами, сезонами и сериями.
3. «Смотреть» → вкладки **качества**; внутри вкладки — **озвучки**.
4. Выбор озвучки запускает лучший подходящий источник; при ошибке внутренний resolver пробует следующую совместимую раздачу.
5. Плеер сохраняет оригинальную визуальную логику Nuvio, прогресс, аудиодорожки, субтитры и D-pad-навигацию.

### Контракт CinemaHall API
В ответе `/stream/{movie|series}/{id}.json`:
- `qualities[]` — вкладки качества (например, 4K / 1080p / 720p), реально найденные для данного тайтла;
- `qualities[].voices[]` — нормализованные названия озвучек и `streamIndex` для разрешённого потока;
- `streams[]` — совместимость с текущим Nuvio API, прямые ссылки только на локальный шлюз.
- Ни ссылок на торрент-файлы, ни сидов, ни магнитов, ни названий раздач в пользовательской модели нет.

Вкладки не рисуются для отсутствующих вариантов. Нельзя считать метку 4K/HDR или озвучку проверенным свойством до анализа файла. Смена варианта должна сохранять позицию, не ломать аудио/субтитры и иметь безопасную отмену.

### Что убрать из оболочки Nuvio
Скрыть из основного пользовательского сценария: обязательный аккаунт Nuvio, управление дополнениями, настройки сторонних провайдеров и раздач, debrid-конфигурацию, техничные списки файлов, диагностику и отладочные экраны. Не удалять их внутренние зависимости до проверки графа вызовов.

### Что оставить
Нативный Media3/mpv runtime и fallback, UI/анимации плеера, настройки изображения/звука/субтитров, главы, история, продолжение, следующий эпизод, библиотеки/профили локального режима, фокус и обработка D-pad.

### Следующая интеграция UI
В Nuvio TV изменяется `StreamScreen.kt`, а в Mobile — соответствующий Compose-экран выбора источника: для `app.cinemahall.catalog` показываем `qualities[]` вместо общего списка потоков. При выборе отправляем связанный `streams[streamIndex]` существующему маршрутизатору воспроизведения. Для иных расширений оставляем их исходную UI-модель на время миграции.

### Требования к каталогам
Единая схема ID, `movie/series`, устойчивые внешние ID, устранение ложных слияний, подтверждённые широкие фоны, постеры, трейлеры/жанры/возраст, рейтинги, сезоны/эпизоды, похожее и коллекции. Снимки для первого открытия + кэш + постраничная загрузка. Ни одного API-ключа в APK. Не вызывать все внешние API на каждый показ карточки.

### Критерии готовности
- TV и Mobile APK собираются в CI.
- Все каталоги и поиск действительно питаются из CinemaHall API.
- Качество → озвучка реально выбирается в TV/Mobile UI.
- Фокус не теряется, нет появления интерфейса торрентов.
- Есть device-тесты воспроизведения, отказоустойчивости и смены источников.
- Функционал прежнего Nuvio не теряется молча.
