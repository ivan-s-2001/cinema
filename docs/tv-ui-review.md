# Проверка интерфейса CinemaHall TV

28 октября 2026 года. Область: старт просмотра, выбор качества/озвучки, смена источника, загрузка карточки. Стек: Android TV, Kotlin, Jetpack Compose / TV Material 3. Пользовательский ориентир — стилистика Nuvio, простая оболочка и небольшой расход ресурсов.

## Использованные материалы

Прочитаны предоставленные архивы: UI/UX Pro Max (`ui-ux-pro-max` и правила native UI), Taste (`redesign-existing-projects`), Ponytail (основной skill и review). Материалы использованы для текущей проверки, без установки новых библиотек или замены стека.

Из UI/UX Pro Max проверены рекомендации о фокусе, устойчивости асинхронной разметки и виртуализованных списках Compose. Запрос `keyboard focus modal` вернул Focus States; `image dimension content jumping` — Content Jumping; `focus state lazy lists` для Jetpack Compose — LazyColumn и стабильные ключи. Примеры CSS не переносятся буквально в Android TV.

Из Taste применяются работа с существующим стилем, ясная иерархия и полноценные состояния загрузки/ошибки. Рекомендации для лендингов, замена шрифтов, размытия, шум, параллакс и декоративные анимации не соответствуют этому ТВ-заданию. Из Ponytail применяется удаление недостижимых веток и повторное использование нативных возможностей. Минимальность не заменяет корректность и проверку изменений.

## Результаты

| Область | Обнаружено | Изменение |
|---|---|---|
| Старт фильма/серии | Первый подходящий источник мог запускаться автоматически | Явное открытие качества/озвучки до запуска плеера, включая кэш и повторный запуск |
| Фокус при пополнении списка | Ключом озвучки был номер строки; вставка могла передать строке другой смысл | Устойчивый ключ группы озвучки и технологии; тот же ключ используется для удаления дублей |
| Сохранение выбора | Смена текста подписи могла создавать дубль известной группы | Проверенная идентичность binge-group имеет приоритет над отображаемым названием |
| Следующая серия | Рекомендованное качество могло заменить выбранную комбинацию | Продолжение с выбранной группой; при её отсутствии открывается выбор |
| Смена источника | Позднее чтение сохранённого прогресса могло заменить живую позицию | Перенос абсолютного времени из плеера до его освобождения, без повторного чтения устаревшей отметки |
| Фон карточки | Загрузочный экран мог получить последний фон главной страницы | Фон перехода привязан к ID нажатой карточки; чужой и отсутствующий фон не подставляются |
| Лишний код | После обязательного выбора осталась недостижимая ветка автоматического выбора CinemaHall | Ветка и оставшийся без производственных вызовов helper удалены |
| Нагрузка | Редизайн мог добавить новые движки, эффекты и зависимости | Используются имеющиеся TV-компоненты, LazyRow/LazyColumn и текущая тема; новых зависимостей нет |

## Границы проверки

Проверены потоки данных и код. Для регрессий добавлены JVM-проверки: ручной старт, сохранение группы следующей серии, устойчивые идентификаторы озвучек, перенос позиции, быстрый переход между карточками и отсутствие подходящего фонового изображения. Результат компиляции и выбранных тестов фиксируется в PR вместе с артефактом APK.

Это не отчёт об измерении кадров/контраста на физическом телевизоре. Читаемость с дивана, аппаратное декодирование, фокус пульта и реальное сетевое воспроизведение требуют проверки на целевом устройстве. Мобильные тесты 375px из общего чеклиста не выдаются за проверку Android TV. Изменение произвольного монтажа файла не выравнивается по содержанию: позиция переносится по абсолютному времени.

Проверка на ТВ: открыть фильм и выбрать качество/озвучку до старта; во время поиска дождаться новых вариантов без потери фокуса; на 12:34 сменить качество и озвучку и проверить позицию; повторить через окно текущей серии; перейти к другой серии и проверить её собственную отметку; быстро открыть другую карточку и убедиться, что загрузка не показывает чужой фон.


## Уточнение 0.7.6

По обратной связи пользователя плеер получил промежуточную насыщенность: верхний логотип, отдельные транспортные и подписанные действия, информацию о серии, время и текущий источник. Скорость/формат/доступные главы собраны в настройках. Две строки предотвращают тесноту подписанных кнопок; направления фокуса между ними заданы явно. Логотип и русская подпись теперь применяются из метаданных и в плеере, а не только на главной/в карточке. Экран выбора озвучки обновляет графику даже при уже известных жанре/годе/хронометраже. Слот изображения имеет фиксированную высоту, декодирование ограничено размером слота. Новых UI-зависимостей нет. Визуальная проверка на физическом ТВ остаётся обязательной частью приёмки.
