# CinemaHall TV 0.7.7: качество и озвучка

Проверено 28 октября 2026 года. Работа продолжает PR №8, базовый commit `497db0b402fc5046eda5d6712bc01e364ab1ea59`. Пользователь выбирает фильм/серию, качество и озвучку. Источники, раздачи, файлы и индексы дорожек остаются внутренними деталями; отдельное меню аудиодорожек не возвращается.

Полезен принцип идентичности файла и разделения проверки контейнера и подписей провайдера. Не переносим произвольный URL в ffprobe и не запускаем массовое сканирование на небольшом VPS. Прочитанный путь ожидает завершения ffprobe без явного общего таймаута, поэтому не является образцом ограниченного ожидания. Код Lampac непосредственно не копировался.

Наше переключение использует уже имеющиеся Media3/MPV, без JS-плеера и нового ffmpeg в APK.

Это пользовательские сообщения, не спецификация алгоритма. ## Реализовано

1. Точные результаты серии возвращаются сразу; независимый поиск сборников продолжается даже при найденной одиночной серии. Общий лимит — 600 уникальных кандидатов; известные карты других эпизодов отбрасываются. Оба поиска продвигаются параллельно через общий предел двух upstream-запросов. На перегрузке очередь/число задач ограничены, ожидание слота входит в сетевой таймаут; ответ режется по байтам во время чтения.
2. Известные написания студий нормализуются только по границам слов. Неизвестная вторая студия и тип перевода не исчезают: `LostFilm / Jaskier` не равен `LostFilm`. Обрабатываем только явно известные алиасы, не угадываем студию по языку.
3. Варианты разделены по качеству/озвучке и видимым HDR/Atmos-подсказкам; fallback не меняет выбранный технологический вариант. Кодек, релизное имя и источник не становятся отдельными пользовательскими вариантами. Подсказки из названия остаются непроверенными.
4. После чтения контейнера Media3/MPV однозначное совпадение названия озвучки применяется к реальной дорожке. Несколько совпадений или один русский язык недостаточны. Реальные озвучки доступны прямо в том же списке под текущим качеством; переключение использует имеющийся native selector без перезапуска файла. Не выводим отдельное меню файлов или дорожек. При ручной смене встроенной озвучки старое автоматическое продолжение сбрасывается, чтобы следующая серия не выбрала прежнюю студию.
5. Подготовка движка и попытки открытия источников используют общий монотонный дедлайн 45 секунд; add/get/rem и чтение первых байтов получают оставшееся время. Разовый запрос имеет принудительное отключение и проверяет полный срок даже при постоянной подаче маленьких порций. Этот бюджет начинается после server discovery; он не объявляется общим временем от нажатия кнопки до первого кадра.
6. TV версия 0.7.7-tv, versionCode 1079. Неактуальный независимый Android workflow не запускается для PR №8; его собственная ветка и ручной запуск сохранены.

## Проверки и границы

Локальные standalone backend-проверки и Java core regression проверяют смешанные сезонные/эпизодные результаты, чужую серию, дедупликацию, перегрузку, byte budget, составные студии, границы технологии и trickle-response deadline. Android CI компилирует реальный provider и TV, запускает выбранные JVM регрессии, затем строит APK. Результаты конкретного CI следует читать по commit изменения.

Нужны физические проверки: MKV с двумя русскими студиями; неизвестные/одинаковые labels; смена озвучки без изменения позиции; 4K DV/HDR; отказ источника; следующая серия и D-pad. До них не заявляем подтверждённое поведение Xiaomi TV.

Постоянный серверный индекс файлов/дорожек, применение студии до первого кадра, HTTP/HLS-поставщики, безопасное обновление существующих APK с постоянной подписью и автоматическая ротация источника после длительного просмотра остаются отдельной работой. Не выдаём первый байт за измерение устойчивой скорости. Backend в этой сессии не развёртывался; миграции БД этим изменениям не нужны.

## Дополнительная проверка данных Zona и JacRed

Один ограниченный запрос метаданных Zona по Kinopoisk ID 361 вернул `filenames` как JSON-массив путей, `files` как path/size map и общую подпись `translate_info`; поля `name` и подтверждённого индекса аудиодорожек в этом образце не было. Это наблюдение одного ответа, не гарантия схемы для всех раздач. Добавлен разбор `filenames`: технические подсказки разрешено брать только из точного mapped-эпизода или единственного видеофайла, с исключением sample. Несколько разных видео без карты не склеиваются в один выдуманный HDR/DV-вариант. Полные списки путей не пересылаются телевизору.

[Lampac JacRed TorrentDetails](https://github.com/lampac-nextgen/lampac/blob/25d80deeb8e6ad075999640f69de1d1ff57c40e6/Modules/JacRed/Models/TorrentDetails.cs) хранит `voices` и `languages` отдельно от `ffprobe`. [ffStream](https://github.com/lampac-nextgen/lampac/blob/25d80deeb8e6ad075999640f69de1d1ff57c40e6/Modules/JacRed/Models/Tracks/ffStream.cs) содержит индекс, codec type, размеры, каналы и tags; [ffTags](https://github.com/lampac-nextgen/lampac/blob/25d80deeb8e6ad075999640f69de1d1ff57c40e6/Modules/JacRed/Models/Tracks/ffTags.cs) — язык и title. Эти данные пригодны для следующего проверенного серверного индекса; наличие поля не доказывает его заполненность у живого источника. HTTP-провайдер и ffprobe-индекс в CinemaHall пока не подключены.
