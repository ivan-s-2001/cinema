# CinemaHall

Android TV кинотеатр: современная оболочка на JetStream Compose, каталог Zona и встроенный TorrServer. Не связан с разработчиками Zona.

## Пользовательский сценарий

Выберите фильм и нажмите **Смотреть**. Приложение само подбирает источник и пробует следующий при ошибке. Пользователь выбирает только качество, озвучку, субтитры и серию. Экранов раздач, сидов, магнитных ссылок или установки TorrServe нет.

## Версия 0.2.0

- Главная: крупный главный блок, горизонтальные полки «Популярное сейчас», «Новинки», «Сериалы», «Продолжить просмотр».
- Разделы «Фильмы», «Сериалы», «Поиск», «Избранное»; карточка фильма с постером и описанием.
- Основа оболочки — официальный Google Android TV Samples / JetStream Compose: адаптированы карточки, правила фокуса и структура главной. Атрибуция и точный upstream-коммит — в THIRD_PARTY.md.
- Автоматический выбор видео: приоритет русского языка, желаемого качества и доступности по каталогу. Для 4K-экрана автоматическая цель — 4K, для остальных — 1080p; фактическая пригодность зависит от источников.
- До шести попыток источников в рамках запуска или выбранных пользователем настроек. Неуспешная подготовка/ошибка воспроизведения приводит к следующей попытке.
- Новый полноэкранный плеер Media3: таймлайн, перемотка с пульта, озвучки, субтитры, серии, скорость и размер изображения.
- Выбор качества и доступных описаний озвучек прямо в плеере без технических названий источников.
- Сохранение позиции, предложение следующей серии и естественная сортировка эпизодов. При переключении источника серия сопоставляется по SxxExx/E или точному имени файла; если совпадение не найдено, другой эпизод автоматически не подставляется.
- TorrServer MatriX.147.1 встроен для ARM64 и ARMv7, API слушает только 127.0.0.1:18990. Кеш видео — 96 МиБ в RAM, не лимит всей памяти процесса.

## Управление плеером

- ОК/вверх/вниз на скрытой панели — показать управление.
- Влево/вправо на скрытой панели или таймлайне — перемотка по 10 секунд; удержание на таймлайне ускоряет шаг.
- Play/Pause на пульте — пауза/продолжение.
- Назад — сначала скрыть панель, повторно — вернуться к фильму.
- Панель автоматически скрывается через 5 секунд во время воспроизведения.
- При HOME/уходе из плеера просмотр завершается, позиция сохраняется, движок останавливается.

## Сборка

JDK 17, Python 3.11+, Android SDK Platform 35. Gradle устанавливает необходимую версию Build Tools.

```sh
python3 scripts/fetch_engine.py
./gradlew :app:assembleDebug :app:lintDebug
```

Бинарники движка не хранятся в Git. Скрипт получает фиксированную версию из официального релиза и проверяет SHA256 до упаковки. Настройки используются без API-ключей.

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Workflow **Android APK** собирает проект и публикует APK в Artifacts. Debug-сборки разных машин могут иметь разные подписи: для постоянных обновлений нужен один постоянный ключ. Ключи в репозиторий не включаются.

Пакет `app.cinemahall.tv`, minSdk 26, targetSdk 35.

## Проверки

```sh
mkdir -p build/check
javac -d build/check app/src/main/java/app/cinemahall/tv/Logic.java tests/LogicCheck.java
java -cp build/check app.cinemahall.tv.LogicCheck
python3 tests/probe_catalog.py
```

LogicCheck проверяет экранирование поиска, безопасность схем ссылок, выбор видеофайлов, определение качества, границы перемотки, формат времени, порядок и идентичность эпизодов, приоритет русского звука. Probe проверяет живую связь карточки и источников без загрузки видео.

## Ограничения

Прототип. Проверки сборки и API не заменяют испытание Android TV: установка, фокус с реального пульта, фактический запуск ARM-движка, декодирование и плавность на Xiaomi проверяются отдельно. Статистика внешнего каталога может быть устаревшей, поэтому автоматический подбор не гарантирует запуск каждого фильма. Все Dolby Vision/HDR и аудиоформаты зависят от телевизора и файла. Неофициальный API Zona не имеет гарантии доступности.

Избранное и история хранятся локально. Нет регистрации, синхронизации, своего сервера или платной подписки. Используйте только контент, к которому у вас есть право доступа.
