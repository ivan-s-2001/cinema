# CinemaHall

Android TV кинотеатр: современная оболочка на JetStream Compose, каталог Zona и встроенный TorrServer. Не связан с разработчиками Zona.

## Пользовательский сценарий

Выберите фильм и нажмите **Смотреть**. Приложение само подбирает источник и пробует следующий при ошибке. Пользователь выбирает только качество, озвучку, субтитры и серию. Экранов раздач, сидов, магнитных ссылок или установки TorrServe нет.

## Версия 0.3.0

- Новая главная: боковая навигация, широкий фон фильма, пять рекомендаций в главном блоке, полки новинок, популярных, сериалов, высокого рейтинга и семейного кино.
- Фильтры по жанру и сортировка по популярности, дате и рейтингу. Поиск, избранное, история, возврат к карточке с пульта.
- Три API без пользовательских ключей: Zona (каталог и видео), Cinemeta (изображения и актёры), TVmaze (сезоны, серии и кадры). Дополнительные API обогащают карточки, не добавляют видеоисточники.
- Cinemeta сопоставляется по точному нормализованному названию и году, TVmaze — по IMDb ID или названию и году. Неоднозначные совпадения пропускаются. Ошибка обогащения не блокирует каталог и просмотр. Кеш метаданных — 24 часа, отрицательные результаты — 1 час.
- Страница фильма: широкий фон, оригинальное название, описание, актёры, похожие фильмы. Для сериалов — сезоны и эпизоды; названия эпизодов могут быть английскими. Наличие метаданных серии не гарантирует наличие её видео.
- Выбор серии перед запуском фильтрует внутренний каталог по SxxExx. Новый сериал начинается с S01E01, просмотренный — с сохранённой серии. При ошибке автоматически пробуются другие источники, без технических списков.
- Плеер Media3: объединённая панель «Качество и озвучка». Вкладки только доступных разрешений: Авто / 4K / 2K / 1080p / 720p / 576p / 480p / 360p / 240p; внутри — озвучки именно этого качества. Для текущего видео также доступны фактические аудиодорожки. Выбор вкладки сам по себе не перезапускает видео; выбор озвучки применяет настройку. Буфер на таймлайне, субтитры, серии, скорость и размер. Позиция теперь привязана к фильму/эпизоду и сохраняется при смене источника. Выбранное качество запоминается, скорость и масштаб сохраняются при переключениях в текущем сеансе.
- Встроенный TorrServer MatriX.147.1 для ARM64 и ARMv7; локальный API 127.0.0.1:18990, RAM-кеш 96 МиБ.
- Официальные компоненты JetStream Compose / Compose for TV сохранены; главный экран и структура навигации переработаны. Атрибуция — THIRD_PARTY.md.

## Windows: собрать и установить на ТВ

В клонированном репозитории:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-tv.ps1 -TvAddress "192.168.8.118:5555"
```

Скрипт сам скачивает JDK 17 и Android SDK в `%LOCALAPPDATA%\CinemaHall\toolchain`, проверяет контрольные суммы, принимает лицензии SDK для сборки, получает встроенный движок, запускает проверку логики, Gradle и lint, подключает ADB, устанавливает и открывает приложение. Python и Android Studio не нужны. При первом запуске скачиваются большие зависимости; повторный использует кеши. Поддерживается Windows PowerShell 5.1, Windows x64.

На ТВ должна быть включена сетевая отладка. Первое подключение нужно подтвердить на его экране. Закрытый GitHub-репозиторий требует авторизации при клонировании.

Если предыдущий APK подписан другим ключом, Android не разрешит обновление поверх. Скрипт объяснит потерю локальной истории и избранного и попросит ввести `ДА` перед переустановкой. Без подтверждения ничего не удаляется. Следующие сборки на этом ПК используют постоянный локальный debug-ключ `%USERPROFILE%\.android\debug.keystore`; сохраните его для будущих обновлений. Ключ не включается в Git.

`-BuildOnly` только собирает APK; `-AcceptReinstall` заранее разрешает удаление приложения при конфликте подписи (с потерей локальных данных).

## Управление плеером

- ОК/вверх/вниз на скрытой панели — показать управление.
- Влево/вправо на скрытой панели или таймлайне — перемотка по 10 секунд; удержание на таймлайне ускоряет шаг.
- Play/Pause на пульте — пауза/продолжение.
- Назад — сначала скрыть панель, повторно — вернуться к фильму.
- Панель автоматически скрывается через 5 секунд во время воспроизведения.
- При HOME/уходе из плеера просмотр завершается, позиция сохраняется, движок останавливается.

## Сборка

JDK 17, Python 3.11+, Android SDK Platform 35. Gradle устанавливает необходимую версию Build Tools.

```sh
python3 scripts/fetch_engine.py
./gradlew :app:assembleDebug :app:lintDebug
```

Бинарники движка не хранятся в Git. Скрипт получает фиксированную версию из официального релиза и проверяет SHA256 до упаковки. Настройки используются без API-ключей.

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Workflow **Android APK** собирает проект и публикует APK в Artifacts. Debug-сборки разных машин могут иметь разные подписи: для постоянных обновлений нужен один постоянный ключ. Ключи в репозиторий не включаются.

Пакет `app.cinemahall.tv`, minSdk 26, targetSdk 35.

## Проверки

```sh
mkdir -p build/check
javac -d build/check app/src/main/java/app/cinemahall/tv/Logic.java tests/LogicCheck.java
java -cp build/check app.cinemahall.tv.LogicCheck
python3 tests/probe_catalog.py
```

LogicCheck проверяет экранирование поиска, безопасность схем ссылок, выбор видеофайлов, определение качества, границы перемотки, формат времени, порядок и идентичность эпизодов, приоритет русского звука. Probe проверяет живую связь карточки и источников без загрузки видео.

## Ограничения

Прототип. Проверки сборки и API не заменяют испытание Android TV: установка, фокус с реального пульта, фактический запуск ARM-движка, декодирование и плавность на Xiaomi проверяются отдельно. Статистика внешнего каталога может быть устаревшей, поэтому автоматический подбор не гарантирует запуск каждого фильма. Все Dolby Vision/HDR и аудиоформаты зависят от телевизора и файла. Неофициальный API Zona не имеет гарантии доступности.

Избранное и история хранятся локально. Нет регистрации, синхронизации, своего сервера или платной подписки. Используйте только контент, к которому у вас есть право доступа.
